### Front basket: мониторинг прайс-индекса

В репозитории лежит `Front basket.xlsx`. Скрипт `monitor_front_basket.py`:

- не изменяет исходный файл;
- создаёт новую копию `Front basket (monitor) YYYY-MM-DD_HHMMSS.xlsx`;
- добавляет колонки `PI <конкурент>` и подсвечивает отклонения > `1.1` (±10% симметрично).

Запуск:

`python monitor_front_basket.py`

или явно файл:

`python monitor_front_basket.py --file "Front basket.xlsx"`

Параметры:

- `--threshold 1.1` — порог (1.1 = 10%)
- `--our "наша цена"` — заголовок колонки нашей цены
- `--competitors "Розница;Розница Х5;..."` — заголовки конкурентов через `;`

Следующий шаг — подтянуть цены конкурентов с сайтов и обновлять соответствующие колонки в новой версии файла (исходник не трогаем).

### Обновление цен конкурентов (через CSV, как тестовый источник)

Поскольку сайты ритейлеров (включая `5ka.ru`) часто включают антибот-проверки (Captcha/“Я не робот”), прямой парсинг может ломаться.
Чтобы уже сейчас строить сравнение, добавлен скрипт `update_competitor_prices.py`, который подтягивает цены из CSV и пишет их в колонку конкурента, затем считает `PI = Цена конкурента / наша цена`.

1) Настрой источники в `competitors.json` (по умолчанию пример для X5 в Новосибирске):
- `xlsx_column`: колонка в Excel, куда писать цену (например, `Розница Х5`)
- `path`: CSV файл вида `barcode,price`

2) Запуск (с генерацией демо-CSV для теста):

`python update_competitor_prices.py --file "Front basket.xlsx" --demo-generate`

Будет создан новый файл `Front basket (updated) ...xlsx` и (если не было) `prices_x5.csv` с демо-ценами `наша*1.15`.
